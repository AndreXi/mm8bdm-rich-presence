# MM8BDM Discord Rich Presence

WIP - Singleplayer only

The objetive of this project is to be an easy way to integrate Discord Rich Presence into the game taking advantage of the logs already given by the game in real time.

Right now my idea is to provide an application where you can pipe the logs directly, so people will add the extra commands to Doomseeker and MM8BDM Launcher and it will work :D

Later I hope to set up pipelines to provide the build and also I will try extend to multiplayer support.
